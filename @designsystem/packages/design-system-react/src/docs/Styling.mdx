# Styling

## Introduction

Components are designed to be **consistent** across all Connected Solutions applications. They include built-in styling that has been
considered carefully, and extensively tested. In general, customing the design system components should be avoided, but most components
do offer control over some simple styling options including:

-   Layout
-   Spacing
-   Color
-   Sizing
-   Positioning

How those are implemented is laid out below

## Spacing

The spacing the design team uses in their design system is based off of variables called `spacing-x` with `x` being a number from 0 to 15.
These variables are used to define the padding and margin of components.

We expose these variables to developers in React via several props that should be available on all components.

These props can be set as follows:

```jsx
import { SolidButton } from '@designsystem/design-system-react'
;<SolidButton margin="spacing-2">Click Me</SolidButton>
```

The spacing props can also be responsive, meaning you can set different spacings for different screen sizes.

```jsx
import { SolidButton } from '@designsystem/design-system-react'
;<SolidButton margin={{ base: 'spacing-0', L: 'spacing-2' }}>
    Click Me
</SolidButton>
```

## Color Props

The color props allow you to set various colors for the element using the design system's predefined color values.

### Available Color Props

-   `color`: Sets the text color of the element.
-   `backgroundColor`: Sets the background color of the element.
-   `borderColor`: Sets the border color of the element.

### Examples

You can set these props as follows:

```jsx
import { SolidButton } from '@designsystem/design-system-react'
;<SolidButton color="General/foreground-primary">Click Me</SolidButton>
```
