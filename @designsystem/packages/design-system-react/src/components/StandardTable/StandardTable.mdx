`StandardTable` provides a design compliant table that supports infinite scrolling, sorting, responsive design, selection, and actions.

## Responsive

The table is responsive by default. It handles this on extra small screens (600px and below) by hiding all columns except for the first.

To try it out, open <a href="./iframe.html?globals=&args=&id=components-standardtable--default" target="_blank">the standard story in a new tab</a> and resize your browser.

## Loading Data

The body supports two types of loading data: auto loading and manual loading.
When `isLoading` is set to `true`, the loading spinner is displayed at the bottom of the table.
When `hasMore` is set to `true`, the loading spinner is displayed at the bottom of the table,
and the `loadMore` function is called when the user scrolls to the bottom of the table.

## Testing

The design system provides a `StandardTableTester` utility to make testing tables easier and more reliable.

### Jest Testing

Here's an example of how to use the `StandardTableTester` in your tests:

```ts
import { StandardTableTester } from '@designsystem/design-system-react-testing'

// Example usage in a test
const user = userEvent.setup()
const table = screen.getByRole('table')
const tester = new StandardTableTester(user, table)

// Wait for any loading to finish
//  - This will wait for the loading spinner to disappear
//  - You won't need this very often as `getRows` will wait for loading to finish automatically
await tester.waitForLoadingToFinish()

// Get all rows and interact with them
const rows = await tester.getRows()
await rows[0].click()

// Check cell content
const cell = rows[0].getCell('Name')
expect(cell).toHaveTextContent('John')

// Check row status
expect(rows[0].getStatus()).toBe('Warning')

// Sort a column
await tester.triggerSort('Name')
```

### Selenium Testing

We provide `StandardTableComponentManager` and `StandardTableRowComponentManager` to help with Selenium UI testing.

#### Initialization

Initialize the component by finding the table element and creating an instance of `StandardTableComponentManager`:

```csharp
new StandardTableComponentManager(
    this.Wait.Until(d => d.FindElement(By.CssSelector("[data-testid=table]"))),
    this.webDriver
)
```

#### Checking if the table is loading

```csharp
bool isLoading = this.tableManager.IsLoading
```

#### Waiting for loading to finish

```csharp
this.tableManager.WaitForLoadingToFinish()
```

#### Getting all rows

```csharp
var rows = this.tableManager.GetRows()
```

#### Interacting with a row

```csharp
rows[0].Click()
```

#### Getting a cell by column name

```csharp
var cell = rows[0].GetCell("Name")
```

#### Getting the status of a row

```csharp
RowStatus status = rows[0].Status
```
